# Jessica Simpson Real Estate Website

Static HTML, CSS and JavaScript website. Includes the enhanced portrait and all website images.

## Deploy
Upload these files to the root of a GitHub repository.

- Vercel: import the repository, select Other, leave the build command empty, and use the repository root as the output directory.
- GitHub Pages: Settings > Pages > Deploy from a branch > main > / (root).

No installation or build step is required.
The inquiry form opens an email draft in the visitor's email app; it does not store submissions.
